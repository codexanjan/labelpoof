# Build and expansion prompts

The current [complete master and MVP prompt](specifications/MASTER-PROMPT.md) supersedes these historical v2 prompts and covers the active cloud model, five specifications, tests and production gates.

## Prototype maintenance prompt

You are maintaining LabelProof v2. Inspect README, PRD, PSD and TRD before changes. Keep the separate landing/dashboard routes, original image persistence, versioned assessments and explicit evidence states. Never convert OCR non-detection into automatic absence. Missing-declaration review requires confirmed applicability, readable-coverage attestation, available images and rationale. Preserve original text and image provenance. Run the unit/API suite, relevant browser checks and production build. Keep synthetic assets labelled and update screenshots/docs for material interface changes. Never commit environment files, credentials or private user images.

## Full production expansion master prompt

Implement the documented production roadmap as a working system: authenticated organizations and reviewer permissions; a tenant-scoped API; PostgreSQL migrations derived from the reviewed production model; private image storage; worker queues and retry-safe jobs; immutable evidence/assessment versions; a reviewed legal rule ingestion/publication workflow; explicit effective dates, applicability and exceptions; auditable corrections; report exports; retention controls and meaningful end-to-end tests.

Use authoritative Indian sources and check the operative documents/amendments before publishing rules. Distinguish observations from rule outcomes. Unknown applicability, unreadable regions and unphotographed surfaces remain unresolved. Never invent licence-verification APIs, clause numbers, performance results or product evidence. Preserve the working v2 dashboard while replacing local adapters with production services. Clearly identify unavailable credentials and implement labelled adapters rather than pretending a service is connected. Keep database design artifacts separate from deployed migrations until validated.

## MVP prompt

Deliver an end-to-end packaged-food review for a narrow documented category: guided photos, real OCR, source-image highlights, a small legally reviewed rule pack, deterministic findings, explicit uncertainty, targeted recapture, manual corrections, immutable versions and PDF/JSON exports. Use original rights-cleared photos or visibly synthetic fixtures. Demonstrate one readable case, one incomplete/unreadable case and one human-reviewed absence. Validate that bad evidence never produces an automatic adverse absence finding. Document setup, source versions, limitations and actual test results.
